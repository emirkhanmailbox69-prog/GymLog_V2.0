# GymLog 2.0 — iPhone-first web app

Первая рабочая итерация нового проекта. Старый GymLog не изменяется.

## Запуск

Откройте `index.html` в браузере или опубликуйте содержимое папки на GitHub Pages. Для локального тестирования модульные скрипты могут требовать локальный HTTP-сервер (например, `python -m http.server 8000`).

## Что уже реализовано

- адаптивная тёмная оболочка с нижней навигацией под iPhone/Safari;
- главный экран, быстрые метрики и история;
- создание тренировки, упражнения, подходы, веса/повторы, отметки выполненных подходов;
- автосохранение активной тренировки и истории в `localStorage`;
- статистика по объёму, длительности и истории;
- первая игровая модель GymQuest: XP, уровни, урон боссу за завершённую тренировку и достижения;
- экспорт/импорт резервной копии JSON с подтверждением перед заменой данных;
- manifest для установки на экран «Домой».

## Ограничения этой итерации

Это стартовый рабочий каркас, а не завершённый продукт. Пока нет миграции данных из старого GymLog, облачной синхронизации, полноценной базы упражнений/шаблонов, редактирования завершённых тренировок, детальной системы PR, настоящих пиксельных игровых ассетов и комплексных автоматизированных тестов. Облачную синхронизацию нельзя добавлять, сохраняя персональный GitHub token в клиентском `localStorage`.

## Проверка

Основные сценарии, которые нужно вручную проверить на iPhone Safari: начать тренировку, добавить упражнение/подход, отметить подход, перезагрузить вкладку, завершить тренировку, экспортировать и импортировать резервную копию. Данные хранятся локально в текущем браузере и не синхронизируются автоматически между устройствами.
